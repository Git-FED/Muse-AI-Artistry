# Contributing

1. Open an issue to discuss larger changes.
2. Keep the existing gallery pages and local image references intact unless a change explicitly concerns them.
3. Keep the root `index.html` as Lumen Home and the promotional page separate at `museai.html`.
4. Use the supplied issue and pull request templates.
5. Check responsive behavior, keyboard navigation, reduced-motion preferences, and relative links.
6. Do not add prices, product capabilities, or legal-compliance claims without owner-provided sources.
